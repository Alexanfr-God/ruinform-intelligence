# RFM-INT-0002.3.1 — Private Live Lab

## Goal

Give the founder a safe first browser surface for testing Material Eye with real photographs without exposing `RUINFORM_API_TOKEN`, `OPENAI_API_KEY`, or `HIGGSFIELD_AUTHORIZATION` to browser JavaScript.

## Changes

- Added `/lab` behind HTTP Basic authentication using server-side environment variables.
- Added direct multipart upload for 1–8 JPEG/PNG/WebP images.
- Images are converted in memory to data URLs and sent directly to Material Eye; the lab does not persist uploaded image bytes.
- The result separates observations from unknowns and shows the Evidence Gate status.
- Added dependency presence indicators for OpenAI and Higgsfield without revealing secret values.
- Added access-control tests.

## Security boundary

The lab password is separate from RUINFORM's API token. Third-party API credentials remain server-side only. The live lab is a founder/testing surface, not the production Workshop experience.

## Next

After live validation, connect the production Workshop through a server-side bridge and replace temporary in-memory uploads with private object storage and signed evidence URLs.
