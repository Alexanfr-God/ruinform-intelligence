# RFM-INT-0003 — Buildable Masterpiece

## Goal

Move RUINFORM from cautious but passive concept generation toward transformed objects that are visually strong, materially honest, and plausible for a human to prototype.

## Product problem observed

The previous Concept Mode often converged on low-risk arrangements such as placing intact objects beside each other. This was technically conservative but missed the product promise: source matter should become a new object. The render stage also ended at a picture, leaving no post-production path for the user to actually make the result.

## Changes

- Form Architect now generates a deliberately diverse portfolio with quick-build, functional, artistic, and ambitious directions.
- Concept Mode treats ordinary missing dimensions as scale-to-fit variables instead of automatic blockers.
- Feasibility Critic distinguishes missing precision from missing safety-critical truth.
- Visible future selection prefers category diversity so the three options are not near-duplicates.
- Visual Brief now asks for legible joins and believable handmade construction rather than seamless fantasy fabrication.
- Concept rendering can use approximate proportions without presenting them as measured facts.
- Added Build Master, a post-production agent that turns an accepted render/candidate into a practical prototype sequence.
- The live lab render action now continues through post-production and displays `MAKE IT REAL` with materials, tools, steps, checks, stop conditions, unresolved properties, and safety gates.

## Non-negotiable trust rules retained

- No invented physical facts are promoted to verified facts.
- High-consequence electrical, thermal, load, pressure, chemical, and material-safety unknowns remain gates.
- No mains-voltage wiring instructions.
- Concept Mode remains exploratory and explicitly unverified.

## Expected behavior

For mixed everyday matter, RUINFORM should produce three visibly different future directions when strong passing candidates exist. At least some internal candidates should favor simple operations and common consumables. A successful render should no longer be the end of the flow; the user receives an adaptive build plan that uses measure-to-fit logic where exact dimensions are missing.

## Regression targets

- Do not regress to three passive arrangements.
- Do not show three near-identical categories when diverse strong candidates exist.
- Do not fabricate numeric dimensions in Concept Mode.
- Do not hide unknown safety-critical facts behind a beautiful render.
- Do not end a successful render without a post-production build result.
