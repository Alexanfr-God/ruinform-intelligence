# RUINFORM — Wave 3 Retrieval Lessons

> This file stores distilled lessons from evaluated real runs. Wave 3 should retrieve these lessons only when they are relevant to the current source set and concept operator.

## Lesson 001 — Interaction leverage over mechanism complexity

**Origin:** evaluated kinetic framed-light artwork (SUCCESS).

### Core rule

Prefer **one simple physical interaction that dramatically changes perception of an ordinary object**.

The mechanism should be:
- simple enough that a normal person can understand and build it;
- physically credible;
- visually secondary to the effect;
- strong enough that the object feels authored rather than decorated.

### Positive pattern

`STATIC OBJECT / ARTWORK → ONE REAL PHYSICAL CONTROL → LARGE PERCEPTUAL CHANGE → MULTIPLE STATES / MOODS`

A small action can create high visual leverage. In the successful framed-light case, one static landscape becomes multiple sunset moments because a real warm light moves behind it.

### Retrieval cues

Retrieve this lesson when the project contains or suggests:
- framed art, translucent / diffusing layers, shadows, light;
- sliders, pull cords, hinges, pivots, shutters, moving counterweights;
- static objects that could reveal multiple states through one user action;
- concepts where a simple movement can change perception more than adding more parts.

### Avoid

Do not use this lesson as an excuse to add a mechanism to every object.

Reject the pattern when:
- the movement does not create a major perceptual change;
- the mechanism becomes the visual hero instead of the effect;
- the build requires precision engineering disproportionate to the payoff;
- decorative complexity is added instead of one clear interaction.

### Visual refinement learned from the run

When the effect uses projected / transmitted light:
- minimize visible rails, channels and light streaks;
- prefer a clean localized optical effect over broad spill;
- hide enough of the trick to preserve magic, but keep the build physically understandable;
- integrate the control element into the final composition rather than treating it as leftover hardware.

### Wave 3 use

This lesson is a **conditional retrieval rule**, not a global prompt instruction.

When relevant, it should bias Design Brain toward concepts with:
1. one dominant physical interaction;
2. high perceptual delta;
3. low added-part count;
4. achievable fabrication;
5. clear collectible authorship.
