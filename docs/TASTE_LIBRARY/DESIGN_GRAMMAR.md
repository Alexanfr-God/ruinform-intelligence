# RUINFORM DESIGN GRAMMAR - v0.1

The Taste Library is useful only if each card contributes a different **design operator**.

## Operators currently curated

1. **WATCHER - Mutate behavior**  
   Make a found/static object do something it normally never does.

2. **LOADBEARER - Turn force into story**  
   Turn real structural necessity - weight, pressure, tension, balance - into visible narrative.

3. **WASTELIGHT - Recompose simply**  
   Find a strong new relationship between ordinary parts without unnecessary complexity.

4. **TRASHLIGHT - Reassign roles**  
   Do not cosmetically upgrade the waste. Give each low-status part a new job.

5. **FLOATRELIC - Expose invisible force**  
   Make a physical phenomenon - magnetism, balance, tension, refraction, movement - part of the visible form.

## Cross-card rules

- Preserve provenance: the source matter should remain legible.
- Do not confuse RUINFORM with one background, color grade or bunker aesthetic.
- Prefer one memorable design move over many decorative moves.
- Complexity must earn its place.
- A strong concept should survive a neutral product shot before the hero-world shot is applied.
- References teach principles, not exact silhouettes.
