# CONCEPT 09 - HEARTWOOD / REVEAL THE INNER VALUE

- **Primary:** MATERIAL / FORM  
- **Secondary:** LIGHT / TRANSFORMATION  
- **Tertiary:** OBJECT / NARRATIVE  
- **Difficulty:** MEDIUM  
- **Operator:** remove_to_reveal  
- **Operator label:** Remove to reveal

## Core formula

`found mass -> identify hidden volume -> remove material -> insert function into the void -> preserve provenance -> collectible object`

## Summary

A found piece of wood is not disguised or transformed into something unrecognizable. Its natural outer form remains legible, while a cavity is created inside it to hold a light source. The result feels as if the light was always inside the wood and the designer simply revealed it.

## Why this card matters

This card teaches a new RUINFORM move: **sometimes design emerges not by adding elements, but by removing material**.

HEARTWOOD introduces a subtractive logic. The found material already contains form, bark, cracks, age, texture and volume. The main design decision is choosing what to cut away and what to keep.

## What the Brain should learn

- Ask: **What is inside this material, and what can be opened, carved out or freed?**
- Treat voids as active design material.
- A function can live inside the found object instead of sitting beside it.
- Removing material can be more powerful than adding decoration.
- Preserve provenance; do not erase the object's past.
- The function itself can help reveal the beauty of the material.
- Subtractive transformation can create collectible value from familiar mass.

## What the Brain must NOT copy

Do **not** reduce this card to tree stumps, Edison bulbs, one vertical slit, dark bark plus amber glow, wooden bases, or rustic lamps as fixed styling.

The transferable lesson is:

> **remove material to reveal a new function while letting the original matter frame it**

## Emotional logic

HEARTWOOD works because the viewer senses that something hidden has been uncovered rather than manufactured. The object feels discovered as much as designed.

## Material language

- found wood / stump / branch mass
- reclaimed wooden base or support block
- bulb or light source
- dark socket and cable

## World signal

The hero world is calm, gallery-like and contemporary. It proves RUINFORM can work with natural matter without becoming generic rustic decor.
