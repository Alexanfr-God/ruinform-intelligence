## Core formula

`ordinary / discarded components -> intervention -> behavior -> collectible object`

## Core lesson

> DON'T DECORATE THE FOUND OBJECT - MUTATE ITS PURPOSE.

## Object idea

A rough painted portrait becomes a physical interactive artifact. A hidden ESP32 / sensor / servo mechanism makes the eyes react to a person, turning a simple static object into a strange collectible / gallery artifact.

## What Design Brain should learn

- Ask what a static object could unexpectedly do: move, react, light, sound, transform, or reveal a hidden mechanism.
- Behavior can be the design, not an extra feature.
- Exposed mechanics may become part of the aesthetic instead of being hidden.

## What Design Brain must NOT copy

- the exact face or giant eyes
- radiation signs
- gas mask
- bunker setting
- brown/orange color grade
- treating the hero-shot atmosphere as the definition of RUINFORM

## Material language

- rough hand painting
- wood
- exposed electronics
- servo
- wires
- imperfect edges
